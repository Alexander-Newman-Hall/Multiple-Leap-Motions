Hand Bridge 2.0.7 for Apple Silicon

Installation

1. Use a Mac with Apple silicon. The app targets macOS 12 or later and
   includes Qt.

2. Install Ultraleap Hyperion 6.2.0 for Apple Silicon in its default location.
   Open Ultraleap Hand Tracking in Applications and complete any first-run
   setup so the tracking service can start. Get the Apple Silicon installer
   from https://www.ultraleap.com/downloads/leap-motion-controller-2/

3. Double-click the Hand Bridge ZIP in Finder. For an upgrade, quit the
   running Hand Bridge controller, then quit handbridge-engine in Activity
   Monitor. The engine normally keeps running after the window closes.
   Drag the extracted Hand Bridge.app to Applications and open it there.

4. This build is locally signed. If macOS cannot verify the developer and
   you trust the copy, try opening the app once, then use Open Anyway in
   System Settings > Privacy & Security (Security & Privacy on macOS 12).
   If macOS reports the app is damaged, obtain a fresh copy of the ZIP.
   Apple's guide is at https://support.apple.com/en-us/102445

Automatic startup

Opening Hand Bridge starts tracking in the background with its saved settings.
Click the hand icon near the clock in the Mac menu bar and choose Open Hand
Bridge whenever you want the controls. Close the window to hide it again.
Quit Controller in the same menu removes the icon and leaves tracking running.
If the engine is already running, the controller reconnects to it. Cameras
can be connected before or after launch. A muted output stays muted.

For unattended startup after you log in, add Hand Bridge.app to your Mac's
Login Items. If you use a scheduler, have it open the app in your logged-in
session. With the app in Applications, the command is

    /usr/bin/open "/Applications/Hand Bridge.app"

Complete the first launch and Hyperion setup once before relying on the schedule.

Verify tracking

1. Open the controls from the hand in the menu bar and connect the cameras
   with USB data cables. Watch Overview for frames. If the app reports a
   missing runtime, install Hyperion and click Start engine to retry.

2. Overview opens on Routed hands. In Devices, choose Both hands for your
   camera. The hand selection applies immediately. Hold one hand over the camera, add your
   other hand beside it, then withdraw the first. Both palms should appear
   together and the remaining palm should keep moving. Choose Right only
   to route just the right hand to the preview and OSC receiver.
   Choose Raw camera in Overview to inspect all hands the camera detects.
   With both cameras attached, Overview should show Cameras streaming 2 / 2. Each
   camera should show a frame rate even with no hands in view. If one stays
   at zero, reconnect just that camera while the other one keeps streaming.

3. For OSC on the same Mac, set the receiver to listen on UDP port 9000.
   Hand Bridge defaults to 127.0.0.1:9000. Move one hand over each camera
   in turn and check that the corresponding receiver channels change.

4. In Devices, check which camera uses each OSC alias. Apply any edits, then
   save a named profile in Profiles & Logs. On the next launch, the engine
   restores those assignments even if the cameras connect in a different order.

5. To drive a Blender hand rig, open OSC Output, enable Full hand skeleton
   and apply the change. Each tracked hand sends an extra OSC message at
   /handbridge/v2/{alias}/{left|right}/skeleton. The message carries raw
   sensor-space geometry in millimeters. The ZIP includes FULL_HAND_OSC.md
   with the field order and handbridge_skeleton.py with a Python decoder.
   When two cameras see one hand, select the calibrated camera alias for that
   hand in the receiving rig. Each camera has its own coordinate system.

Send errors counts failed OSC sends since the engine started. When the total
gets large, the dashboard abbreviates it. Hover over the number to read the
full count. The Output stage badge shows whether sending has recovered.

Source and licenses

The companion Hand-Bridge-2.0.7-Source.zip includes the source, tests and
build instructions for this build. Published Hand Bridge releases are at
https://github.com/Alexander-Newman-Hall/Multiple-Leap-Motions/releases

Hand Bridge's own code uses the MIT License. The app dynamically links Qt
6.8.3 under LGPLv3. The v2.0.1 release includes the matching Qt sources.
In Finder, choose Show Package Contents on the app and open Contents/Resources
for LICENSE, Third Party Notices.txt, the Qt source manifest and license texts.
